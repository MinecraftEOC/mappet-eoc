# GUI проверки D20

`ui.dice()` создаёт компонент, но не открывает GUI. До вызова `roll()` кубик
статичен и по умолчанию расположен по центру родительского контейнера.
Компонент также доступен через `ui.create("dice")`. Все необходимые текстуры включены в мод.

## Использование

Готовый скрипт: [examples/dice-check.js](examples/dice-check.js).
Назначьте его игроку, чтобы `c.getSubject()` был игроком.

```javascript
function main(c)
{
    var ui = mappet.createUI(c, "handler").background();

    // Статичный кубик, сложность слева сверху, основа справа сверху.
    ui.dice().difficulty(15).base(5).id("dice");

    ui.button("Бросить").id("roll")
        .rx(0.5).ry(1, -28).wh(160, 20).anchorX(0.5);

    c.getSubject().openUI(ui);
}

function handler(c)
{
    var context = c.getSubject().getUIContext();

    if (context.getLast() === "roll")
    {
        // Миллисекунды, сложность, исходный результат D20, основа.
        context.get("dice").roll(2400, 15, 12, 5);
    }
    else if (context.getLast() === "dice")
    {
        // Штатное событие GUI, как у кнопки. Отдельный callback не нужен.
        var data = context.getData();
        var total = data.getLong("dice.total");       // 17
        var outcome = data.getString("dice.outcome"); // "success"
        var skipped = data.getBoolean("dice.skipped");

        c.send("Результат: " + total + ", исход: " + outcome
            + (skipped ? " (анимация пропущена)" : ""));
    }
}
```

`difficulty(value)` и `base(value)` принимают целые неотрицательные числа.
`roll(durationMs, difficulty, result, base)` принимает исходный результат от 1 до 20,
проверяет аргументы и обновляет оба боковых блока. Сам бросок определяет ваш скрипт;
компонент показывает переданное число, а не генерирует случайное.

Задайте `id("dice")`, чтобы получать событие завершения и менять компонент после
открытия GUI. Обновления из обработчика GUI отправляются штатным механизмом Mappet.
При изменениях из другого скрипта вызовите `context.sendToPlayer()`.

## Последовательность и результат

1. Вращение нужное число полных циклов, затем остановка и статичный кубик.
2. Анимация исходного числа поверх кубика: золотое при `result >= difficulty`,
   иначе красное.
3. Копия числа основы вместе с плюсом плавно перелетает к кубику за 600 мс.
   Исходный блок основы остаётся на месте.
4. На кубике заново проигрывается анимация суммы `result + base`.
   Цвет определяется по `sum >= difficulty`.
5. Под кубиком проигрывается соответствующая надпись результата.
6. После её последнего кадра отправляется одно событие GUI с ID кубика.
   Итоговое число и надпись остаются видимыми.

Натуральная **1** — всегда критический провал, красное число 1.
Натуральная **20** — всегда критический успех, золотое число 20.
В обоих случаях основа не прибавляется, перелёт и анимация суммы пропускаются,
сложность не влияет на исход. Надпись критического результата и событие остаются.

После запуска броска **ЛКМ в любом месте открытого GUI** немедленно показывает
окончательные число и надпись и отправляет то же событие один раз.
Этот клик не нажимает кнопку под курсором. До запуска и после завершения
кубик клики не перехватывает. ПКМ анимацию не пропускает.

`reset()` отменяет бросок без события завершения и возвращает статичный кубик без
результата и надписи; боковые блоки остаются. Новый `roll()`, в том числе с теми
же параметрами, запускает последовательность заново.

## Данные события

Пример ниже использует ID `dice`; при другом ID префикс меняется.

| Ключ | Чтение | Значение |
| --- | --- | --- |
| `dice` | `getInt` | Счётчик завершённых бросков |
| `dice.sequence` | `getLong` | Номер команды запуска |
| `dice.result` | `getInt` | Исходный D20 |
| `dice.total` | `getLong` | Сумма либо исходная 1/20 для критического исхода |
| `dice.difficulty` | `getInt` | Сложность из вызова `roll` |
| `dice.base` | `getInt` | Основа из вызова `roll` |
| `dice.success` | `getBoolean` | Успех с учётом критических исходов |
| `dice.critical` | `getBoolean` | Выпала 1 или 20 |
| `dice.outcome` | `getString` | `success`, `failure`, `critical_success`, `critical_failure` |
| `dice.skipped` | `getBoolean` | Анимация завершена нажатием ЛКМ |

Параметры результата фиксируются при запуске: изменение видимого `difficulty()`
или `base()` во время броска не меняет его итог. Сумма хранится как `long`,
чтобы основа, близкая к пределу `int`, не приводила к переполнению.

## Время и масштаб

Первый аргумент `roll()` сохраняет старую логику: это запрошенное время
**вращения вместе с остановкой**, без последующих эффектов результата.
Для встроенных текстур цикл вращения — 400 мс, остановка — 1600 мс.
Вращение занимает `max(0, durationMs - 1600)`, округлённое вверх до 400 мс.
Даже `roll(0, ...)` проигрывает полную остановку.

Например, `roll(2400, ...)` — два цикла вращения и остановка, всего 2400 мс.
Обычная проверка затем занимает ещё 2100 мс: число 500, перелёт 600,
сумма 500, надпись 500. Критическая — ещё 1000 мс: число и надпись.
`roll(2500, ...)` округляет время кубика до 2800 мс.
Отрицательное время отклоняется.

Длительности кадров чисел, надписей, вращения и остановки читаются из
`.png.mcmeta` штатным парсером Minecraft; один тик — 50 мс.
При замене ассетов меняются и длительности соответствующих фаз.
Каждый кубик имеет независимый клиентский таймер, обновления с сервера на каждый
кадр не нужны. При низком FPS время сохраняется, промежуточные кадры могут пропускаться.

Исходный размер кубика — **64×64 GUI-пикселя**. `dice.wh(128, 128)` увеличивает
весь рисунок вместе с блоками и надписью вдвое. Сохраняются квадратные пропорции;
для прямоугольного компонента берётся меньшая сторона. Если боковые блоки
не помещаются на экране, масштаб всей группы автоматически уменьшается.
`xy()`, `rxy()` и `anchor()` работают как у остальных UI-компонентов.

## Совместимость и свои текстуры

Старый `roll(durationMs)` сохранён: он проигрывает только кубик и удерживает
статичный кадр, без чисел и надписи. При заданном ID также отправляет событие
завершения (`dice.outcome = "none"`).

```javascript
dice.textures(
    "eoc:textures/gui/dice/d20_spin.png",
    "eoc:textures/gui/dice/d20_stop.png",
    "eoc:textures/gui/dice/d20_rest.png"
);
```

Этот метод заменяет только кубик. Цифры и надписи можно заменить ресурс-паком
по путям `assets/mappet/textures/gui/dice/widgets_v2/...`.
Учитываются `frametime`, порядок и повторение `frames`, отдельные значения `time`,
явные `width` и `height`. Интерполяция кадров не поддерживается:
используйте `interpolate: false`. Последний кадр каждого эффекта удерживается.
При F3+T кэш размеров и метаданных очищается.

Реализация использует существующие `UIComponent`, регистрацию типов,
NBT-передачу изменений, `GuiElement`, менеджер текстур и `GuiDraw`.
Завершение отправляется через тот же `UIContext.dirty()`, что и нажатие кнопки,
без нового вида пакетов или отдельной callback-системы.
