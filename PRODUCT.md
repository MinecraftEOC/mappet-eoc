# Mappet EOC

Mappet EOC — форк Mappet для Minecraft 1.12.2. Мод даёт авторам приключенческих карт и администраторам ролевых серверов инструменты для создания игровых сценариев внутри Minecraft. Игроки проходят квесты, взаимодействуют с NPC и видят интерфейсы, заданные авторами сценариев.

## Текущие возможности

- NPC, диалоги, задания и цепочки квестов, фракции.
- События, условия, триггеры и регионы, а также состояния мира и игроков для сценарной логики.
- JavaScript API для работы с миром и игроками, создания GUI и HUD. В форке реализованы дополнительные триггеры, включая `eoc_player_tick`, и автоматическая перезагрузка скриптов при изменении файлов.
- Компонент `ui.dice()` отображает анимированную проверку D20 со сложностью, бонусом и критическими исходами. Исходное число задаёт скрипт. По завершении компонент передаёт результат в обработчик GUI. Пример использования и поля события описаны в [документации D20](docs/dice-ui.md).

## Технический стек

- Minecraft 1.12.2, Forge 14.23.5.2860 и JDK 8. Сборка использует Gradle Wrapper 7.4.2 и ForgeGradle 5.1.73, тесты — JUnit 4.
- McLib и Metamorph обязательны по декларации Forge. Сборка также использует dev-версии Blockbuster и Aperture из `run/libs`.
- Сценарии выполняются через Nashorn. Данные мода хранятся в сохранении мира, в том числе в каталоге `mappet/`. Для работы не требуется отдельная БД.

## Правила и ограничения

- Изменения должны работать на Minecraft 1.12.2 и Java 8. Клиентский интерфейс и рендеринг не должны загружаться на выделенном сервере.
- При изменении форматов сохранения и JavaScript API нужно учитывать существующие карты, сценарии и имена полей событий.
- В проверке D20 натуральная 1 даёт критический провал, натуральная 20 — критический успех. В обоих случаях бонус не прибавляется. Пропуск анимации сохраняет тот же итог и вызывает событие завершения один раз.
